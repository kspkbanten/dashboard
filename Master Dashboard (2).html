📖 Tentang Dashboard

Selamat datang di Dashboard Pemantauan Terpadu Capaian Program Pembangunan Keluarga. Dashboard ini menghadirkan gambaran realisasi capaian terhadap target program prioritas pembangunan keluarga Kemendukbangga-Perwakilan BKKBN Provinsi Banten sehingga keputusan dapat diambil lebih cepat, tepat, dan berbasis data.

Program prioritas yang dipantau:

TAMASYA GATI SIDAYA 1000 HPK UPPKA SATYAGATRA POKTAN TRIBINA

Informasi dihimpun dari kanal resmi SIGA, Website SIDAYA, Portal GATI, dan YO-SAKURGA, lalu dikompilasi menjadi Dashboard Program Prioritas Pembangunan Keluarga untuk mempermudah proses monitoring dan evaluasi program di tingkat provinsi hingga kabupaten/kota.
